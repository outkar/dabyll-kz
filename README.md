# Dabyll.kz, прототип

Сайт для конкурса АБРК «Твори, дерзай, побеждай»: цифровая система защиты клиентов банков от онлайн-мошенников.

## Что внутри

index.html, styles.css, app.js: сам сайт (5 разделов по ТЗ).
icons/: иконки из ТЗ.
api/chat.js: серверная функция Vercel для Ai-жәрдем, ходит в Anthropic API.

## Деплой на Vercel

1. Залей папку в новый репозиторий на GitHub.
2. На vercel.com: Add New → Project → выбери репозиторий. Framework Preset: Other. Build Command и Output Directory оставь пустыми.
3. До нажатия Deploy открой Environment Variables и добавь:
   ANTHROPIC_API_KEY = ключ с console.anthropic.com (нужен пополненный баланс, $5 хватит)
   ANTHROPIC_MODEL = claude-haiku-4-5-20251001 (необязательно, это значение по умолчанию)
4. Deploy. Если ключ добавила после деплоя, сделай Redeploy, иначе функция его не увидит.

Проверка ИИ: открой раздел Ai-жәрдем и нажми любую подсказку. Если под полем ввода появилась надпись «Желі жоқ…», значит API не ответил и работают запасные ответы. Причину смотри в Vercel → Project → Logs.

## Сменить модель или провайдера

Модель меняется переменной ANTHROPIC_MODEL. Чтобы перейти на другого провайдера (Gemini, OpenAI), переписывается только блок fetch в api/chat.js, фронтенд трогать не нужно: он ждёт от /api/chat ответ вида {"reply": "текст"}.

## Что в прототипе имитируется

4143 это условный номер сервиса, звонок показывается как имитация.
SOS-Ескерту открывает WhatsApp или SMS с готовым текстом, отправку подтверждает сам пользователь. Контакты и имя хранятся только в браузере (localStorage).
Жедел бұғаттау не блокирует карту сам: у прототипа нет доступа к банкам. Он принимает только банк и последние 4 цифры и выдаёт инструкцию и номер банка.
Если интернет или API недоступны, Ai-жәрдем отвечает заготовками по ключевым словам.

## Локальный запуск без ИИ

python3 -m http.server 8000, потом открыть http://localhost:8000. Чат будет в запасном режиме.
Для локального запуска с ИИ: npm i -g vercel, затем vercel dev (ключ положить в .env.local).
